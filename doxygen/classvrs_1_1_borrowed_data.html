vrs::BorrowedData Class Reference

Class to hold borrowed data that is not copied into the record's buffer, like DirectWriteRecordData, but which can be compressed together with the DataSource payload. The borrowed segments are written after the DataSource payload, in order: compressed with it when the record is compressed, or raw when it isn't. Multiple segments let non-contiguous memory regions be borrowed as one payload. owner keeps the borrowed memory alive until the record is written, which may happen later on a background thread. Detailed Description

Class to hold borrowed data that is not copied into the record's buffer, like DirectWriteRecordData, but which can be compressed together with the DataSource payload. The borrowed segments are written after the DataSource payload, in order: compressed with it when the record is compressed, or raw when it isn't. Multiple segments let non-contiguous memory regions be borrowed as one payload. owner keeps the borrowed memory alive until the record is written, which may happen later on a background thread.
